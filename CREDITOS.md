# Créditos y licencias de recursos

## Imágenes y gráficos

**No se utilizan imágenes de terceros.** Todas las piezas visuales del sitio son
originales y se generan en el propio proyecto:

| Recurso | Origen | Licencia |
| --- | --- | --- |
| `static/favicon.svg` | Diseño propio (monograma JL) | Uso libre en este proyecto |
| `static/og-image.svg` | Diseño propio (imagen de Open Graph) | Uso libre en este proyecto |
| Portadas de proyectos (`ProjectCover.svelte`) | SVG generado por código | Uso libre en este proyecto |
| Retícula, halos y lluvia digital | CSS + Canvas generado por código | Uso libre en este proyecto |
| Icono de GitHub | Trazo de marca (Simple Icons, CC0-1.0) | CC0-1.0 |
| Icono de LinkedIn | Trazo de marca (Simple Icons, CC0-1.0) | CC0-1.0 |

No se incluyen capturas de pantalla de los proyectos porque ninguna estaba
disponible como recurso público en los repositorios; se priorizó no usar
imágenes de relleno sin valor.
